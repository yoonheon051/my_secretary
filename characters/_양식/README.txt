새 포켓몬 추가하는 법
=====================

1. 이 "_양식" 폴더를 통째로 복사해서 같은 characters 폴더 안에 붙여넣고, 폴더 이름을 영어로 바꿔요. (예: pikachu)
   - 폴더 이름이 _ 로 시작하면 도감이 건너뛰어요. 이름을 바꿔야 나타나요.
2. 그 폴더에 평소 모습 그림을 character.png 로 넣어요. (필수)
3. species.json 을 메모장으로 열어서 아래 설명대로 고쳐요.
4. 나몰빼미 상태 카드(우클릭)의 이름을 눌러 도감을 열면 새 포켓몬이 보여요.
   "함께 키우기"를 누르면 바꿔서 키울 수 있어요. 친밀도·배부름·기분은 포켓몬마다 따로 저장돼요.


1) 평소 모습 그림 (필수)  ─  character.png
   - 배경이 투명한 PNG. 왼쪽을 보고 있는 그림이어야 해요. (오른쪽으로 걸을 때는 자동으로 뒤집어요)
   - 크기는 아무래도 괜찮아요. 높이가 약 126픽셀보다 크면 높이 110픽셀로 자동으로 줄여서 써요.
   - 눈·입 좌표(아래)는 "넣은 그림 그대로의 픽셀 위치"로 적으면 돼요. 줄일 때 같이 줄어들어요.
     (그림 편집 프로그램에서 마우스를 올리면 보이는 좌표를 쓰면 돼요. 왼쪽 위가 0,0)


2) 배고픈 모습 · 자는 모습 · 뾰로통한 모습  ─  눈과 입 모양만 바꿔요 ("poses")
   그림을 따로 만들 필요 없이, 평소 그림 위에 눈과 입을 덧그려요.

   "eyes" (눈 모양):  open 그대로 / closed 감은 눈 / squint 질끈 감은 눈 > < / half 반쯤 감긴 눈 / happy 웃는 눈
   "mouth" (입 모양): none 없음 / open 벌린 입 / frown 삐죽 / flat 일자 / smile 웃음

   기본값: hungry = squint + open,  sleep = closed + none,  grumpy = half + frown
   모양을 바꾸고 싶으면 poses 안의 값만 고치면 돼요.
   "image" 에 파일 이름을 적으면(예: "hungry.png") 눈·입 덧그림 대신 그 그림을 써요. (왼쪽을 보는 투명 PNG)

   덧그리려면 아래 좌표가 필요해요 ─ 0 이면 아무것도 안 그려요(평소 그림 그대로).
   "eyes": [[왼쪽눈 x0, y0, x1, y1], [오른쪽눈 x0, y0, x1, y1]]
           눈 하나를 딱 감싸는 네모의 왼쪽 위(x0,y0)와 오른쪽 아래(x1,y1)
   "mouth": [x, y]       입(또는 부리)의 가운데
   "face": 눈을 덮을 때 쓰는 얼굴 색 (눈 주변 색과 같게)
   "outline": 눈·입을 그리는 선 색


2-1) 입이 이미 그려진 그림  ─  "mouth_box": [x0, y0, x1, y1]  ─  평소 그림에 입이 이미 그려져 있을 때, 그 입 전체를 감싸는 네모.
   표정을 바꿀 때 이 자리를 얼굴 색으로 먼저 덮고 새 입을 그려요. 입이 안 그려진 그림이면 null.


3) 날개  ─  "wings": false
   true 는 나몰빼미의 날개 모양을 그대로 쓰는 것이라 다른 포켓몬에는 어울리지 않아요. false 로 두세요.
   (날아다닐 때 날개 대신 몸만 움직여요)


4) 볼 단계  ─  "balls"  (포켓몬마다 달라요)
   - "level": 친밀도 레벨이 이 값 이상이면 그 볼. 맨 처음 볼의 레벨은 1.
   - "name": 볼 이름
   - "style": 뚜껑 무늬. plain 없음 / super 양옆 띠 / hyper 띠 셋 / master 동그라미 둘과 M
   - "colors": [뚜껑 색, 무늬 색, (안 씀·아무 색), 가운데 띠 색]   (없으면 null)
   볼 개수는 마음대로 늘리거나 줄일 수 있어요.


5) 도감에 보이는 정보
   "no" 번호, "name" 이름, "en" 영문 이름, "kind" 분류, "types" 타입(풀·불꽃·물·전기 …),
   "desc" 설명, "web" 웹 도감 주소(없으면 "").
